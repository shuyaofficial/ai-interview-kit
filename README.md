# AI 模擬面接（パソコン版）

就活の面接練習を、自分のパソコンの中だけでできるアプリです。ES（エントリーシート）の添削、声で答える模擬面接、採点レポートまでそろっています。

## 何ができるか

- ES の添削: 設問ごとに、良い点と直したい点を返します。
- 音声の模擬面接: AI の面接官が声で質問し、あなたが声で答えます。
- 採点レポート: 面接のあとに、点数と「次はこうすると良い」をまとめます。
- 5分の練習と、15分の通し面接を選べます。
- 手ごわい面接官で練習: 理詰め・圧迫・無反応・時間制限の面接官で、答えにくい質問に慣れます。

## 必要なもの

- Mac か Windows のパソコン（マイクつき）
- Node.js 22 以上（このアプリを動かすための土台になるソフトです。https://nodejs.org から入れられます）
- ChatGPT のアカウント。Codex CLI（ChatGPT のアカウントで動く、文字で操作する AI ソフト）に、そのアカウントでログインしておきます。

## 起動

ターミナル（Windows は PowerShell）で、このフォルダを開いて次を入力します。

```
npm start
```

表示されたら、ブラウザ（Chrome をおすすめします）で http://127.0.0.1:8979 を開きます。止めるときはターミナルで Ctrl + C を押します。

最初のマイクの許可は「許可」を選んでください。

## データについて

ES や面接の記録は、このフォルダの中の `data/` に保存されます。自分のパソコンの外へ、このアプリが勝手に保存することはありません。消したいときは `data/` フォルダを消してください。

## 注意

- 音声の面接は、Codex の「試験中」の機能を使っています。将来、仕様が変わって動かなくなる可能性があります。
- ChatGPT の無料プランで動くかどうかは、確かめられていません。動かないときは有料プランが必要かもしれません。
- 面接で話した内容や ES の文章は、採点のために OpenAI（ChatGPT の会社）に送られます。ほかの人の個人情報や、会社の秘密は入れないでください。
- Gemini の音声（Google のサービス）は、あなた自身の API キー（利用のための合言葉）があるときだけ使える、おまけの機能です。なくても全部の機能が使えます。
