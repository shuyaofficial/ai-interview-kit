# 採点の規則
- 根拠は応募者（candidate）の発言だけ。evidence と quote には、該当ターンの text を一字一句そのままコピーした部分文字列（10〜80字）を入れる。要約・言い換え・補完をしない。turn はそのターン番号。
- 引用できる根拠が無い軸は、高い点を付けない（最大2）。
- 甘く採点しない。話し方が丁寧でも、内容に事実と数字が無ければ specificity は2以下にする。「頑張った」「色々工夫した」だけの回答は1〜2にする。
- 平均点を3に寄せない。尺度の記述に合う段をそのまま付ける。
- ES と面接回答の食い違いは consistency で減点し、reason に両方の内容を書く。
- 音声認識の誤り（同音異義・固有名詞の崩れ）は減点しない。

- 各回答は、質問の裏の意図に答えているかで見る。裏の意図は「仕事で何ができるか」と「どう思っているか（意欲・考え）」の2つ。表面の質問に答えただけで、この2つのどちらも伝わらない回答は responsiveness を3以下にする。
- 大学より前の経験だけで答えた回答は、specificity を3以下にする（面接官が知りたいのは直近の努力の過程）。
- 志望動機が「同業他社ではなくこの会社」の理由を含まない場合、motivation は3以下にする。

# 質問ごとの評価（questions）
- 面接官の主な質問ごとに1件。深掘りへの回答はその質問の評価に含める。questionTurn は面接官のターン番号。
- good と improve はそれぞれ1〜2文で、具体的に書く。improve は人柄の評価ではなく「面接官が知りたい点をつかみ損ねた箇所」として書く（例:「結果は伝わったが、そこに至る自分の工夫が抜けている」）。
- modelAnswer は応募者が話した事実と ES の事実だけを使い、結論先出し・STAR・300字以内で書き直す。新しい経験や数字を作らない。足りない事実は「（ここに〇〇の数字）」と空欄で示す。

# 書き方
- 応募者が読む文（reason, good, improve, summary, nextPractice）に、内部の項目名（quote, turn, evidence, questionTurn など）や、この採点規則そのものへの言及を書かない。引用をどう扱ったか・空欄にしたかなど、採点の手順の説明も書かない。「ターン3」ではなく「2つ目の回答」のように書く。
- 回答が記録されていない質問は、good に「回答が記録されていません」とだけ書く。

# 全体（overall）
- summary は3文以内。
- nextPractice は次回の練習で直す点をちょうど3つ、行動で書く（例:「ガクチカの結果を最初の一文で数字とともに言う」）。
