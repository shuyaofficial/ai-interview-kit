# 採点（各 1〜5 の整数）
- prep: 冒頭で結論を述べ、理由→具体例→結論の順か。5=一文目で要点が分かる。1=結論が無い。
- specificity: 状況・課題・自分の行動・結果がそろい、数字や比較があるか。5=STAR と数字がそろう。1=抽象語だけ。
- length: 字数が設問の目安（{{limit}}字）の9割〜10割か。5=9割以上で超過なし。3=7割程度。1=半分以下か超過。

# 規則
- comments の quote には、ES の原文をそのまま一字一句コピーする（要約しない）。指摘は1設問につき2〜4個。
- rewrite は本人が書いた事実だけを使って書き直す。新しい数字・経験・役職を作らない。足りない事実は「（ここに〇〇の数字を入れる）」と空欄で示す。
- 甘く採点しない。具体的な数字が1つも無ければ specificity は2以下にする。
- plan.focusPoints は3〜5個。面接官が「本当か」「なぜか」を確かめたくなる箇所を選び、probes に深掘り質問を2〜3個ずつ書く。
- 本籍・家族・宗教・思想・支持政党・尊敬する人物・愛読書・住宅・健康には触れない。
